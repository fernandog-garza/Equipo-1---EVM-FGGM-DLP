# Propósito del repositorio
Este repositorio consiste en pequeños proyectos que se irán desarrollando semanalmente, pero esos pequeños proyectos tendrán como objetivo el desarrollo de uno más elaborado. Los invitamos a darle un vistazo a las carpetas que se encuentran aquí, para que nos dejen sus comentarios o puedan tomar inspiración para un proyecto suyo :) 

Archivos del repositorio

Los archivos que se encuentran en este repositorio están separados en carpetas correspondientes a las semanas de trabajo en el proyecto. Dentro de las carpetas, se encuentran los archivos de las siguientes cosas: 

-Diagrama del circuito electrónico

-Programa de arduino (.ino)

-Un reporte en PDF donde se explica el proyecto.

-Un video en donde se muestra el circuito funcionando.

Este repositorio se estará actualizando cada semana
